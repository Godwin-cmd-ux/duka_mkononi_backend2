OBJECTIVE
---------
Implement strict role-based branch assignment for sellers in the existing
multi-branch Dukamkononi backend:

- Sellers are permanently assigned to ONE business_id + ONE branch_id.
- Sellers cannot switch branches or see cross-branch records.
- On login, sellers are auto-redirected to their assigned branch dashboard.
- If the assigned branch is inactive/unavailable, login must be rejected.
- Sellers must never see a branch-selection screen or cross-branch records.
- Backend enforces seller scope for products/inventory/sales/customers/etc.
  (frontend concealment is not security).
- Non-branch sellers/businesses keep existing behavior; existing sellers
  preserved.
- Added audit + incremental implementation + tests + report.
