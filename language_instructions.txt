# 10. LANGUAGE SELECTION

When the user clicks a language button:

1. Determine the selected language.
2. Update the current website language.
3. Translate the homepage immediately.
4. Store the selected language in the current session/state.
5. Ensure the language survives navigation to the next page.

For example:

User opens homepage.

Current language:

Swahili

User clicks:

English

The homepage immediately changes to English.

Then the user clicks:

Login

The login page must automatically open in English.

---

# 11. LANGUAGE MUST SURVIVE NAVIGATION

This is extremely important.

The selected language from the homepage must not disappear when the user navigates to another page.

Example:

Homepage
↓
User selects French
↓
Homepage becomes French
↓
User clicks Login
↓
Login page MUST automatically be French

The user should NOT have to select French again.

The selected language should be stored in the appropriate website session/state mechanism.

Use the existing Laravel/session architecture where appropriate.

Do not create an unnecessary duplicate state-management system if Laravel's existing session can handle the requirement.

# 15. AUTHENTICATION LANGUAGE BEHAVIOR

Before login:

The language comes from the current website session/state.

After successful login:

The system must know the user's selected language.

The successful login process must:

1. Authenticate the user.
2. Create/update the normal authenticated session.
3. Preserve the selected language.
4. Update the user's preferred language in Supabase if this is missing from the current implementation.
5. Store the user's language preference so it can be retrieved later.

The language preference belongs to the user, not merely the browser session.

---

# 16. DATABASE LANGUAGE PREFERENCE

The system must distinguish between:

### Guest user

Language comes from the current website session/state.

### Authenticated user

Language should ultimately be associated with the user's account in Supabase.

Therefore:

Guest:

`homepage → selected language → session → login`

Authenticated user:

`login → selected language → Supabase user preference`
